## 👤 2. Employee Dashboard Testing

### 2.1 View Attendance Status

**Login as:** `test.employee0@company.com` / `Test@123`

#### Step-by-Step:
1. **Navigate to:** `/dashboard/employee`
2. **Check:** Attendance status card
3. **Expected Result:**
   - ✅ Shows current status (Logged In / Logged Out)
   - ✅ Shows today's date
   - ✅ Shows login/logout times if logged in
   - ✅ Timer displays if currently logged in

### 2.2 Mark Attendance - Login

#### Step-by-Step:
1. **Navigate to:** `/dashboard/employee/attendance`
2. **Click:** "Mark Login" or "Check In" button
3. **Expected Result:**
   - ✅ Success message appears
   - ✅ Status changes to "Logged In"
   - ✅ Login time is recorded
   - ✅ Timer starts counting
   - ✅ Button changes to "Mark Logout" or "Check Out"

#### Verify in Database:
- Check that attendance record is created for today
- Login time is recorded correctly

### 2.3 Mark Attendance - Logout

#### Step-by-Step:
1. **After logging in, wait a few minutes**
2. **Click:** "Mark Logout" or "Check Out" button
3. **Expected Result:**
   - ✅ Success message appears
   - ✅ Status changes to "Logged Out"
   - ✅ Logout time is recorded
   - ✅ Total hours calculated correctly
   - ✅ Timer stops

#### Verify:
- Total hours = (Logout time - Login time)
- Attendance record updated in database

### 2.4 View Attendance History

#### Step-by-Step:
1. **Navigate to:** `/dashboard/employee/attendance`
2. **Scroll to:** Attendance history/logs section
3. **Check:** Date range filter (if available)
4. **Expected Result:**
   - ✅ List of attendance records displayed
   - ✅ Shows date, login time, logout time, total hours
   - ✅ Records sorted by date (newest first)
   - ✅ Can filter by date range

### 2.5 Apply for Leave

**Login as:** `test.employee0@company.com` / `Test@123`

#### Step-by-Step:
1. **Navigate to:** `/dashboard/employee/leaves`
2. **Click:** "Apply for Leave" or "New Leave Request" button
3. **Fill in form:**
   - Leave Type: Select "Earned Leave"
   - Start Date: Select a future date (e.g., 7 days from now)
   - End Date: Select end date (e.g., 2 days after start date)
   - Reason: Enter "Personal work"
   - Number of Days: Should auto-calculate
4. **Click:** "Submit" or "Apply" button
5. **Expected Result:**
   - ✅ Success message: "Leave application submitted"
   - ✅ Leave appears in "Pending" status
   - ✅ Leave balance decreases (if auto-approved) or stays same (if pending)
   - ✅ Notification sent to approver

#### Verify:
- Leave record created in database
- Status is "pending"
- Leave balance not yet deducted (until approved)

### 2.6 View Leave Balance

#### Step-by-Step:
1. **Navigate to:** `/dashboard/employee/leaves`
2. **Check:** Leave balance section
3. **Expected Result:**

## 🐛 Bug Reporting Template

When you find issues, document them with:

1. **Title:** Brief description
2. **Steps to Reproduce:** Detailed steps
3. **Expected Result:** What should happen
4. **Actual Result:** What actually happened
5. **Screenshot:** If applicable
6. **Browser/Device:** Chrome, Firefox, etc.
7. **User Role:** Which role you were logged in as
